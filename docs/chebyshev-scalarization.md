# Скаляризация augmented Chebyshev

Реализация: `tidyhebo/layered/scalarization.py`. Используется при локальном
поиске начальных точек/батчей и финальном уточнении. **NSGA-III получает исходную
тройку AF**, со сменой знака для минимизации в pymoo, а не скаляризацию.

## 1. Исходные критерии и замороженный масштаб

Для точки или полного батча X вычисляется тройка максимизируемых критериев:

$$s(X)=(\operatorname{LogEI}(X),\operatorname{PI}(X),\operatorname{UCB}(X)).$$

Для q > 1 это совместные qLogEI, qPI и qUCB. На каждом уровне поиска отдельно
рисуется калибровочная выборка из N = `calibration_samples` Sobol-кандидатов.
Точечный и батчевый уровни имеют **разные экземпляры** `Scalarizer`.

$$\ell_i=\min_{k=1,\ldots,N}s_i(X_k),\qquad
\Delta_i=\max\left(\max_k s_i(X_k)-\ell_i,\;10^{-10}\right).$$

`__init__` вычисляет и отсоединяет эти тензоры от графа градиентов. Они не
пересчитываются в ходе Adam/GA. `losses` переводит максимизацию в минимизацию:

$$L_i(X)=1-\frac{s_i(X)-\ell_i}{\Delta_i}.$$

Минимум AF в калибровке переходит в 1, максимум — в 0. Для постоянного критерия
получается L = 1. Новые значения **не обрезаются** до [0,1]: улучшение за пределами
калибровки продолжает давать градиент.

## 2. Луч и обратные веса

Направления r берутся из сетки Das–Dennis на симплексе. Для направленного
локального поиска выбираются `directions` лучей этой сетки. Код `direction`
заменяет нулевые и слишком малые координаты:

$$\widetilde r_i=\max(r_i,\varepsilon_r),\qquad
\varepsilon_r=\texttt{direction\_floor}=0.02.$$

После этой операции луч не нормируется. Код `weights` вычисляет:

$$w_i=\frac{1}{\widetilde r_i}.$$

Это **обратные** координаты геометрического направления. При равных активных
взвешенных отклонениях w_i v_i получается v_i пропорционально r_i. Прямые веса
r_i означали бы другую постановку. Для граничного луча используется его
регуляризованная версия; точное движение по исходной границе не гарантируется.

При `normalize_weights=True` дополнительно применяется

$$\widehat w_i=\frac{w_i}{\sum_j w_j}.$$

По умолчанию нормировка выключена. Для фиксированного луча она умножает весь
скалярный функционал на положительную константу, сохраняя его математические
минимизаторы; конечная численная траектория Adam может отличаться.

## 3. Отклонение и augmented Chebyshev

Задаётся единая опорная точка z_i = −0.05, чуть лучше нулевой калибровочной
потери. Это опорная точка, а не доказанная глобальная идеальная граница.

$$v_i(X)=L_i(X)-z_i=L_i(X)+0.05,\qquad a_i(X;r)=w_i v_i(X).$$

`__call__` минимизирует функционал

$$\boxed{\Phi(X;r)=\max_i a_i(X;r)+\rho\sum_i a_i(X;r)},\qquad
\rho=\texttt{rho}=0.01.$$

Максимум управляет худшим взвешенным отклонением. Добавка учитывает улучшение
остальных критериев, даже когда активный максимум не меняется. При rho = 0
получается неаугментированный вариант. Строго положительные веса и rho > 0
делают функционал строго возрастающим по каждой потере; это свойство не
превращает конечный локальный поиск в гарантию глобального Парето-оптимума.

В реализации **нет модуля** |v_i|. Вне калибровочного диапазона v_i может стать
отрицательным: функционал продолжает поощрять улучшение, а не притягивает к z.
Это signed achievement scalarization, а не расстояние до опорной точки.

В точках смены активного максимума функционал негладкий. `torch.amax` даёт
субградиент; сглаживающей температуры здесь нет.

Для m = 1 сохранена отдельная ветка: Phi = L_1 − z_1, без весов и добавки.
В текущем layered-поиске всегда m = 3.

## 4. Использование в локальном поиске

- Якоря максимизируют один исходный критерий: минимизируется −s_i(X).
- Направленные кандидаты минимизируют Phi(X;r).
- Каждый restart — отдельная строка общего тензора Adam. Лучи и веса
  транслируются по ведущим измерениям; последняя ось всегда соответствует AF.
- После шага координаты проецируются в [0,1]. Для каждого restart сохраняется
  лучший допустимый результат, включая исходный старт. Допустимость означает
  отсутствие наблюдённых точек и повторов внутри батча.
- Сравнение проводится для одной численной AF с фиксированными QMC-семплами.
  Оно не даёт гарантии по неизвестной настоящей целевой функции.

## 5. Числовой пример

Пусть калибровочные минимумы равны (0,2,4), максимумы — (2,6,10), а текущие
AF равны (1.3,3,9). Тогда

$$L=(0.35,0.75,1/6),\qquad v=(0.40,0.80,13/60).$$

При r = (0,0.4,0.6) после floor получаем веса w = (50,2.5,5/3), поэтому

$$a=(20,2,13/36),\qquad
\Phi=20+0.01(20+2+13/36)\approx20.2236111.$$

Этот пример и градиент проверяет `tests/test_layered_config.py`.
