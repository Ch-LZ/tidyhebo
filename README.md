# How to install
Requires python 3.10+

#### to use
- download repo
```shell
pip install tidyhebo
```
#### to develop
`-e` flag is requried to avoid reinstallation while editing in place
```shell
pip install -e tidyhebo[dev]
```

to run tests `pytest tidyhebo/tests`

see tidyhebo/example/example.ipynb
